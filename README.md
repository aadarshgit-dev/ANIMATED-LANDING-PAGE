# Scrollify – Animated Landing Page

Scrollify is a modern and interactive landing page built using HTML, CSS, JavaScript and GSAP. It focuses on smooth animations, engaging transitions and an immersive user experience through motion design.

🌐 **Live Demo:** https://scrollify.onrender.com

## Features

- Smooth entrance animations using GSAP.
- Timeline-based animations.
- Scroll-triggered animations using ScrollTrigger.
- Stagger effects for multiple elements.
- Interactive UI elements.
- Smooth transitions and modern layouts.

## Tech Stack

- HTML5
- CSS3
- JavaScript
- GSAP (GreenSock Animation Platform)
- GSAP ScrollTrigger

## Getting Started

### Clone the repository

```bash
git clone https://github.com/aadarshgit-dev/ANIMATED-LANDING-PAGE.git
```

### Navigate to the project directory

```bash
cd ANIMATED-LANDING-PAGE
```

### Run locally

Open `index.html` in your browser or use the Live Server extension in VS Code.

## Key Learnings

- Working with GSAP timelines.
- Implementing scroll-based animations.

- Using JavaScript to create interactive web experiences.
- Improving UI/UX through motion design.
