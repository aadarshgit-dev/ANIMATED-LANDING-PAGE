# Animated Landing Page

A modern and interactive landing page built using HTML, CSS, JavaScript and GSAP. This project focuses on smooth animations, engaging transitions and an improved user experience through motion design.

## Features

- Smooth entrance animations using GSAP.
- Timeline-based animations.
- Scroll-triggered animations using ScrollTrigger.
- Stagger effects for multiple elements.
- Interactive UI elements.
- Smooth transitions and modern layouts.

## Tech Stack

- HTML5
- CSS3
- JavaScript
- GSAP (GreenSock Animation Platform)
- GSAP ScrollTrigger

## Getting Started

### Clone the repository

```bash
git clone https://github.com/aadarshgit-dev/ANIMATED-LANDING-PAGE.git
```

### Navigate to the project directory

```bash
cd ANIMATED-LANDING-PAGE
```

### Run the project

Open `index.html` in your browser or use the Live Server extension in VS Code.
